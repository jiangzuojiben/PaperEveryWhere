# ReadPaper 当前账号迁移与页面批注验收

本轮按用户要求只使用文件、离线渲染、数据库和命令行构建，未操作桌面界面。适配依据为先前保存的 ReadPaper 1.29.0 及阅读器参考样本；重新实现转换和显示逻辑，发行物不包含原程序 JavaScript。

| 文件夹 | 30（18 顶层、12 子目录），89 条实际文献分类关联 |

| 独立附件 | 88 次附件列表读取成功，实际 list 全为空 |

页面叠加包括 139 条有坐标的文字选区、32 个截图选框、7 个文本框、11 个矩形和 1 个箭头。源记录共 211 条；19 条选区记录没有几何坐标，唯一旧手写资源的 `drawModelArray` 为空，另有 1 个零尺寸图形。这 21 条保留为原始记录及页面笔记，不生成虚构位置。没有未解决的可绘制源记录。

## 转换与数据保护

- 选区和截图框使用未旋转 CropBox 左上坐标，按页面旋转变换后归一化；图形和文本框本来就是显示页坐标，不二次旋转。另用非零 CropBox 和四种旋转 fixture 测试。
- 保留源颜色；选区透明度 0.3，截图框填充 0.1。文本框按参考的 950 单位字号和默认尺寸系数 1.2 转换。原自定义字号间距设置未导出，字体度量可能存在细微差异。
- 箭头端点与方向保持；翼部尺寸根据标准折线重建。原翼部 CSS 未取得，报告明确标记近似。
- 原 PDF 字节不变。批注绑定 PDF 哈希和页码，原始记录保留在笔记中，并与新叠加建立关联。
- 写入前 SQLite 一致性备份，单事务提交；重复执行保留用户修改及删除状态，标识冲突、缺失来源笔记或版本变化时回滚。非空但尚未适配的手写数据明确拒绝，避免静默漏迁。
- 本地工作区数据库已写入 190 条叠加；705 条待同步操作的引用依赖顺序核对通过。此结果不表示已上传任何云端账号。

## 离线验证与交付

`scripts/convert_readpaper_annotations.py` 生成清单、转换覆盖报告并应用叠加；`scripts/verify_migration_overlays.py` 生成单独批注页 PDF、验证全部 126 页确有可见叠加，并回读工作区核对 88 个文件哈希、190 条叠加及其来源笔记链接。人工离线抽查高亮、截图框、中文文本、箭头和旋转页 PNG。

迁移包构建器 `scripts/package_readpaper_migration.py` 采用明确文件白名单，包含 88 份原 PDF、用户原始导出、32 资源、原页码映射的 35 份批注页预览、转换结果、CSV 索引、恢复脚本、脱敏数据库快照和说明。清除 JSON 中的认证字段与签名 URL 查询参数；不包含登录状态、设备偏好、原程序代码或重复历史备份。ZIP 每个成员重新读取校验 SHA256，快照再次检查 SQLite 完整性及全部原件哈希。

Windows 和 Android 共享渲染逻辑已构建成新的批注迁移版 ZIP/APK；未安装、未启动应用或模拟器。桌面界面最终对照、移动实机与 iOS 验收仍待完成，不能据此将产品标记为完整复刻已验收。

测试结果和归档 SHA256 以 `artifacts/annotation-migration-build-verification.json`、完整迁移包的 `checksums.json` 及同名包外校验报告为准。
