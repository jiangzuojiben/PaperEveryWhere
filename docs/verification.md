## 本轮发现并修复

1. Windows 中文路径导致 Flutter 分析器协议错误：使用临时 ASCII 盘符映射构建。
2. Kotlin 缓存跨盘符失败：关闭增量编译，改为进程内编译。
3. Android SQLite 不含 FTS5，而 Windows 使用的 SQLite 不含 FTS4：先尝试 FTS5，缺失时回退 FTS4；中文查询提供子串匹配。
4. pdfrx 搜索器过早创建导致阅读器启动崩溃：移动到文档就绪回调。
5. 手机键盘出现时笔记面板空间不足：批注列表高度跟随剩余空间调整。
6. 上传元数据补全后丢失同步确认：发送前持久化准确负载，确保同一操作重放不变。
7. PDF 直线无可见外观、Helvetica 丢失中文：增加外观流和 CJK 字体资源，保留笔迹压感宽度。
8. Windows 备份临时 SQLite 连接未关闭：显式关闭，备份及空目录恢复回归通过。
9. 本机 ADB 服务版本冲突：模拟器使用独立 5041 服务端口。一次后续复跑的调试连接停滞，结束该测试进程后改用规范模拟器 ID，最终复跑成功。
