# 功能对照及验收边界

“已实现”表示代码存在且可进入对应路径；不等于已证明与 ReadPaper 全量行为相同。原版内部运行样本及移动实机均未完成观察。

0.5默认入口为 [ReadPaper云端文献/阅读/批注＋自有AI](online-mode.md)，客户端不持久保存业务数据。专用文献的真实批注/笔记/进度写回及PDF上传、去重和下载哈希验证已通过；原生版本选择及匹配上传经真实服务与独立会话字节核对通过；上游可能跨版本共享批注，已提示坐标核对。手写路径读取/删除已补，原生新增尚未打通。逐项来源、代码和用例见 [0.5验证](readpaper-live-write-20261023.md)。下表保留0.3本地优先版本的历史实现状态，新模式未适配功能不能从下表推定可用。

## 尚未关闭的原版兼容义务

1. 登录后的 Windows 文献库与阅读器逐屏对照；原版批注、离线同步和冲突行为实验。
2. Android/iOS 原版样本、移动实机手写与性能验证，iOS 签名构建。
3. 当前账号可读取数据的迁移已完成离线核对；其他账号/版本、非空旧手写与 v3 手写格式、来源已删除或不可读取数据仍需单独验证。
4. 图表候选已实现，完整矢量/表格解析、图搜论文仍未实现；DOI 补全和笔记分类已补齐，富文本实时协作仍未实现。
5. 大型 PDF/大文献库性能基线、容器恢复演练与真实 AI 服务质量验收。

这些项目阻止将 v0.3.0 标记为“完整复刻已验收”。
