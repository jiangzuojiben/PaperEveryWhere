# Git 历史隐私脱敏说明

2026-10-25，在用户明确授权改写远端历史后，整理 `main` 与本地相关分支历史。

- 将私人提交邮箱替换为本账户已有的 GitHub noreply 地址；作者显示名称和提交日期保留。
- 将 9 份历史文档/研究报告中的本机 Windows 用户目录段替换为 `[user]`。这些路径现在是脱敏占位符，不应视为可直接访问的实际目录。
- 产品源码、截图、测试样本、原有提交说明及非目标文件的 Git 对象保持不变；原始 GitHub 签名提交保留。
- 新提交继续使用 noreply 邮箱，防止再次携带私人提交邮箱。

路径脱敏会改变相关报告文件本身的字节与校验值。历史测试所测的产品 bundle、程序、样本及截图没有因本次处理而改变；原验收记录不应被解释为对脱敏后报告字节重新做过同一轮测试。

扫描范围为已获取分支/标签可达的提交历史、文件内容与提交元数据，并补查媒体文件元数据。没有全面执行图片 OCR，也不能保证发现所有未知格式的秘密。原始恢复备份与详细映射仅保留在本机被忽略的 `output` 目录，不随普通 Git 推送上传；这些本地备份仍包含脱敏前信息，请勿公开分享。

远端分支改写只清理新分支可达的历史。已有克隆、fork、GitHub 缓存或直接引用旧对象的页面不会因此自动消失。本机既有便携包亦不会因 Git 历史改写而自动重新生成；分享旧产物前需单独检查其中的报告和路径信息。
